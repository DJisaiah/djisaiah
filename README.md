### about me

enjoy building things from scratch. python and java are where i got started, but lately i've been spending more of my time writing go and typescript to expand my backend experience. i also enjoy writing C whenever i get the excuse.

most of my projects start because i want something for myself, then slowly turn into things other people can actually use. long-term i'm interested in systems programming, electronics, and eventually the intersection of computing and biology.

my top 3 tech has to be linux, vim (not neovim), and go.
